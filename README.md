# 🎓 CampusVerse

**Navigate Your Campus. Connect With Your Community.**

CampusVerse is a smart campus navigation and student engagement web application designed to improve the overall college experience. It combines interactive campus mapping with gamification to help students explore their college, locate important places, and connect with the campus community.

## 🚀 Key Features

- **Interactive Campus Map:** A custom-designed 1D–1.5D map that makes campus navigation simple and intuitive.
- **Indoor Navigation:** Uses campus photographs and visual layouts to help students identify classrooms, departments, laboratories, offices, and other important locations.
- **Player Cards:** A gamified student profile system designed to encourage participation, interaction, and engagement.
- **User-Friendly Interface:** Simple and accessible design for first-time users.
- **Student Engagement:** Creates a more connected and interactive campus experience.

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python, Django
- Database: To be integrated
- Map System: Custom visual campus mapping

## 🎯 Our Vision

Our vision is to transform traditional campus navigation into an interactive digital experience while building a connected student community through gamification.
